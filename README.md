# Primus Hotel Booking System
A console-based hotel booking system developed in Java as part of my **Foundation in Science & Technology* programming course. 

This project was one of my first experiences developing a complete software application. It introduced me to fundamental programming concepts such as modular programming, user input handling, decision-making, loops, methods, and basic object-oriented programming. 

## Overview

The system simulates a hotel self-booking application where users can:
- select a room theme
- choose the number of nights
- add extra beds
- select additional hotel services
- calculate the total booking price
- confirm the booking

The project was developed as a console application using Java.
